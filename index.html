C# / FULL-STACK WEB APPLICATION

ResolveIT

IT Support Ticket Management System

After seeing a campus post about a Wi-Fi issue, I wanted to explore how support requests could be recorded and tracked in one place. I built ResolveIT with ASP.NET Core MVC, learning the framework as I developed my first C# web application.

  • Create, view, edit and delete support tickets
  • Set priorities and update ticket statuses
  • Store ticket records using Entity Framework Core and SQLite
  • C#
  • ASP.NET Core MVC
  • EF Core
  • SQLite
  • Razor
  • Bootstrap

CISCO × WETHINKCODE_ HACKATHON / TEAM

Solar Esy

AI-assisted community energy prototype

Our hackathon concept explored how households could identify energy shortfalls, receive saving recommendations and simulate matches with nearby solar surplus. I worked on UI/UX, system architecture, the planning flow, prototype development and the pitch.

Energy transfers, metering and settlement were simulated. This is not a live electricity-trading platform.

  • UI/UX
  • System design
  • Energy-planning logic
