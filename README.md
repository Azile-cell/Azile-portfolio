## Featured Projects

### ResolveIT
**IT Support Ticket Management System**

My first C# web application built with ASP.NET Core MVC after learning the framework through Microsoft Learn.

Key features include:

- Creating and managing support tickets
- Ticket priorities and status tracking
- Editing and deleting support requests
- Persistent database storage using Entity Framework Core and SQLite
- Razor views and Bootstrap-based interface

**Technologies:** C#, ASP.NET Core MVC, Entity Framework Core, SQLite, Razor, Bootstrap

🔗 Repository: https://github.com/Azile-cell/Resolve-IT

---

### Solar Esy
**AI-Assisted Community Energy Prototype**

Developed during the Cisco × WeThinkCode_ She Builds Tomorrow Hackathon for the Smart & Sustainable Futures track.

The prototype explored how households could identify electricity shortfalls, receive energy-saving recommendations and simulate matching with available community solar surplus.

My contributions included:

- UI/UX design
- Problem research
- System architecture
- Energy-planning workflow
- Prototype development
- Pitch preparation and presentation

The hackathon prototype simulated electricity matching, metering and settlement rather than performing real electricity trading.

---

### WorkFlow AI
**Workplace Productivity Prototype**

Built during the CAPACITI AI Skills Acceleration Programme.

WorkFlow AI helps structure workplace activities such as emails, meeting notes, task planning and research. The current prototype uses local rules and structured templates rather than a paid generative AI API.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS

🔗 Live Prototype: https://ai-productivity-assistant-ebon.vercel.app/  
🔗 Repository: https://github.com/Azile-cell/AI-Productivity-Assistant
