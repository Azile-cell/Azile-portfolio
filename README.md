# Featured Projects

## ResolveIT
### IT Support Ticket Management System

ResolveIT is a web-based IT support ticket management application developed using **C#, ASP.NET Core MVC and Entity Framework Core**.

The project was created to explore how a structured software application could support the reporting and management of IT support requests.

### Key Features

- Create and manage support tickets
- Record issue descriptions and priorities
- Track ticket status
- Edit and delete support requests
- Persistent database storage using Entity Framework Core and SQLite
- Razor-based views with a Bootstrap interface

**Technologies:**  
C#, ASP.NET Core MVC, Entity Framework Core, SQLite, Razor, Bootstrap

🔗 **Repository:**  
https://github.com/Azile-cell/Resolve-IT

## Solar Esy
### AI-Assisted Community Energy Prototype

Solar Esy was developed during the **Cisco × WeThinkCode_ She Builds Tomorrow Hackathon** for the Smart & Sustainable Futures track.

The prototype explored how households could estimate electricity needs, identify potential shortfalls, receive energy-saving recommendations and simulate the use of available community solar surplus.

### My Contributions

- Problem research
- UI/UX design
- System architecture
- Energy-planning workflow design
- Prototype development
- Presentation preparation
- Responding to questions about the solution during the team Q&A

The hackathon prototype simulated electricity planning, matching, metering and settlement concepts rather than performing real electricity trading.

# Running the Portfolio Locally

Clone the repository:

```bash
git clone https://github.com/Azile-cell/Azile-portfolio.git
```

Navigate into the project directory:

```bash
cd Azile-portfolio
```

The portfolio is a static website, so you can open `index.html` directly in your browser.

Alternatively, use a local development server such as the **Live Server** extension in Visual Studio Code.
