# Azile Gomomo Portfolio — Final Version

This is the polished responsive portfolio website.

## Open locally
1. Extract the ZIP.
2. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a browser.

## Deployment
The site can be deployed to GitHub Pages, Netlify or Vercel.

## Included
- Responsive desktop, half-screen/tablet and mobile layouts
- UJ Compass live demo and GitHub links
- Final CV download
- Skills with technology and Microsoft Office icons
- Education, learning programmes and certifications
- GitHub, LinkedIn and contact links
- Visible fixed Back to top control
